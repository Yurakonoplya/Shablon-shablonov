# work/: ход текущих задач

Здесь агенты договариваются в моменте: ведущий кладёт задания исполнителям, исполнители кладут отчёты, а [current-state.md](current-state.md) одной страницей говорит, что шаблон умеет, что обкатывается и чего ждём сегодня. Это не список дел на будущее и не место для материалов и результатов работ.

## Как устроено

- **Крупная задача получает папку** с понятным именем (`first-release/`, а не `task-7/`): в ней задания и отчёты, один файл на задание и один на отчёт. Задача, которой хватает одного задания, папки не заводит.
- **Если проекту нужны свои разделы отчёта**, они записываются здесь.
- **Законченная задача уходит целиком**, вместе с отчётами и журналами прогонов. К этому моменту всё, что из неё нужно знать и дальше, уже записано на постоянном месте, а сама она остаётся в истории git. Когда здесь лежат только этот файл и current-state.md, задач в ходу нет.
