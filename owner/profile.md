# Профиль владельца

Значения владельца по темам профиля шаблона. Сами темы, как их узнать и что берётся по умолчанию, живут в одном месте: [template/project/profile.md](../template/project/profile.md); здесь только то, что у владельца иначе, чем по умолчанию, с датой и источником (из какой работы или поправки взято).

Профиль не заполняется анкетой: значение появляется из материалов владельца и его поправок к плану, в той же задаче, в которой стало известно. Совпадает с умолчанием шаблона, строки нет.

## Как записывать

По теме заголовок, как в профиле шаблона, под ним строка на значение:

```
## Чем располагает

- Телефон Samsung на Android, iPhone нет (по метаданным съёмки, 12.10.2026).
- Платные сервисы сейчас не оплачивает; каждый платный прогон только с его согласия (поправка к плану, 15.10.2026).
```

Отказ от приёма по обстоятельствам (нет устройства, нет денег) записывается здесь как факт, а не в шаблоне как оценка приёма: для другого пользователя приём остаётся в силе.

*(Темы и значения появляются по ходу обкатки.)*
