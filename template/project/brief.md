# Форма задания на работу

Что должно быть известно о каждой работе, чтобы получить результат. Всё, что у пользователя постоянно, сюда не входит: оно в [профиле](profile.md).

Это карта того, что нужно для результата, а не анкета: заполнять всё не обязательно, и пользователя об этих полях не спрашивают списком. Агент снимает с материалов всё, что можно снять; пустое поле закрывается тем, что пользователь может дать, или подбором агента с пометкой «не подтверждено». Заполненное задание лежит в README папки работы.

**Материалы идут первыми.** Что можно взять из файлов пользователя (чертежа, съёмки, текста, ссылки), берётся оттуда, а не спрашивается. Текстовое описание обычно даёт для результата меньше, чем кажется: у двух разных работ оно может совпадать слово в слово.

Форма переписывает себя в работе: не хватило поля, оно добавляется; значение одинаково у всех работ пользователя, оно переезжает в профиль; поле выводится из других данных, оно заменяется правилом с пометкой, на скольких работах проверено; поле, которое ни разу не пригодилось, убирается. Каждое такое изменение это строка в [журнале](journal.md).

Пометки у поля: **[из материалов]** снимается с того, что принёс пользователь; **[выбор]** одно значение из набора в профиле; **[правило?]** бывает, что выводится из других данных.

*(Поля этой работы, сгруппированные по смыслу. Пример из другой работы, рендер дома: «Объём» (пятно дома, форма кровли, высота окон, терраса: всё [из материалов], с чертежей), «Отделка» (схема отделки по объёмам, тон дерева [выбор], кровля [выбор]), «Постановка кадра» (где вход, куда смотрит сад: на чертежах этого обычно нет). Пример для ролика: цель ролика для продукта, хук, история по участкам с предметом на экране в каждом, что нужно от автора. Заполняется при обкатке; если результат не собирается из заранее известного набора данных, этот файл удаляется вместе со строкой в таблице CLAUDE.md.)*
