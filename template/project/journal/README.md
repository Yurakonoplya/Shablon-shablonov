## Как вести

Запись появляется, когда изменилось одно из двух: **что получает пользователь** или **причина, по которой проект устроен именно так**. Правка, не задевшая ни того ни другого, записи не заслуживает. Сама работа записывается в README своей папки в work/, а не здесь; сюда идёт решение, которое она принесла.

Кратко: **что → почему → к чему ведёт.** Новое сверху тома, дата в формате `ДД.ММ.ГГГГ`, по факту, когда пользователь это увидел.

Поломка или промах: обязателен последний абзац «чему учит», как заметили и что теперь мешает повториться.
