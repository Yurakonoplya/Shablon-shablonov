# Принципы результата

По этим принципам проверяется каждый план и каждый результат до показа пользователю. Меняются они осознанно, записью в [журнал](journal.md), а не молча.

Принцип это утверждение с причиной и проверкой: без причины его отменят по недоразумению, без проверки его нельзя применить. Принципов немного: только то, что верно всегда и для любого пользователя. Что верно по поводу, живёт инструментом в [tools/](../tools/README.md); что верно для одного пользователя, в его [профиле](profile.md).

*(Заполняется при обкатке. Форма каждого принципа: жирное утверждение одной фразой; почему так: причина вне вкуса, в зрителе, заказчике, площадке, материале; проверка: по какому признаку в плане или результате видно, что принцип соблюдён. Пример из другой работы: «У каждого утверждения в ролике есть предмет на экране. Зритель ленты в режиме потребления и рассказ без показанного предмета опознаёт как болтовню. Проверка: в плане нет участка длиннее пяти секунд без предмета».)*
