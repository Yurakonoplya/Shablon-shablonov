# План работ (бэклог)

Единственное место, где живут задачи на будущее. Второго списка дел в проекте нет.

Полный список задач одной строкой каждая, чтобы понять расклад, не открывая ничего. Значки: 🔴 сейчас · 🟡 следом · ⚪ потом.

## Как это устроено

Задача, которой есть что сказать о себе, получает отдельный файл рядом с понятным именем (`second-version.md`, а не `task-7.md`). Внутри четыре вещи: **зачем**, **что должно получиться** (проверяемый признак), **что известно**, **границы**. Мелочь живёт строкой в списке выше.

Сюда идут только задачи. Текущая работа живёт в своей папке в [work/](../work/README.md), решения в [журнале](../project/journal.md).

**Закрытая задача уходит отсюда совсем**: строка убирается, в журнал ложится запись, что получилось, файл задачи удаляется. Так этот файл остаётся списком будущего, а не отчётом о прошлом.
