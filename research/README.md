# Исследования

Здесь то, по чему **решение ещё не принято**: разведка, пробы и замеры, разбор чужих методов, черновики «как это можно было бы сделать».

Главное правило: **принято решение, и его вывод уходит отсюда** одной внятной формулировкой туда, где действует, а файл остаётся здесь обоснованием, «почему решили именно так». Обратной дороги нет: передумали, отменяем решение записью в [журнале](../project/journal/README.md), а не возвращаем вопрос сюда.

Пока вопрос открыт, ему место тут, иначе следующая сессия примет черновик за решение и начнёт на нём строить. В шаблон исследования не входят: пользователю нужен вывод, а не путь к нему.

Читать отсюда точечно, по списку ниже, а не подряд. Имя файла это вопрос, на который исследование отвечает (`voice-cleanup.md`, а не `research-1.md`).
