# docs/: рабочий справочник проекта

Точные процедуры, которые нужны **при исполнении**, а не при понимании. Открывать точечно, под конкретную задачу.

Сюда попадает только то, что относится к этому проекту как к месту, где делается шаблон: проверка и выдача. Процедуры самой работы (как монтировать, как рендерить, как собирать сайт) сюда не идут: они часть шаблона и живут в [template/tools/](../template/tools/README.md), иначе пользователь их не получит.

## Что здесь лежит

- [blind-run.md](blind-run.md): обкатка по эталону вслепую: как разложить эталоны пользователя (вход отдельно от ответа), порядок прогона с закрытым эталоном, две корзины расхождений. Открывать, когда у пользователя обкатки есть готовые результаты, с которыми сверяется шаблон.
- [release.md](release.md): выдача шаблона пользователю: проверка чистоты и полноты template/, прогон незнакомым агентом, передача. Открывать перед каждой выдачей.
